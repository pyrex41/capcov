- **On every capcov workload `.4` matches `.3`** to within 0.4%, with identical payloads and exit code 0.
- **The guard pays off** only where a typecheck starts with no hypothesis or no datatype, which is where 43.1.1 copied the term for nothing.
  - `mb-terms` is built for that case: it runs `shen.typecheck` 20000 times over 6 terms, with `[]` hypotheses and no datatypes.
  - `.4` brings `mb-terms` back to 43.1's level; guard117 measured 67.72 G for 43.1.
  - Its payloads are identical across builds: `mb-terms` `5f220f8056cb0e15`, `mb-defs` `9bad4b46696a9092`.
- **How the typed batch was counted.** macOS counts instructions only for the direct child of `/usr/bin/time`. So the batch ran `TypedAuthorityDifferentialTest` with `BIFROST_SHEN_SCHEME` pointing at a wrapper that runs each shen-scheme call under `/usr/bin/time -l`. The wrapper sits next to a `lib` symlink into the store path. Each run made 2 calls, and all 4 tests passed with 3148 units.
- **CPU time** on this host varies by more than these differences, so it is not reported.
