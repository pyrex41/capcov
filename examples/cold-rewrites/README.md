# Cold rewrite evals — agent prompt stubs

These are assignments, not implemented adapters, pinned benchmarks, or results. Use [jo](jo.md) as a small CLI control. For a performance-oriented database project, use the [projection and timing protocol](database-projection.md) with one engine card: [DuckDB analytical kernels](duckdb.md), [SQLite VM programs](sqlite.md), or [LMDB transactions](lmdb.md). For distributed storage rather than query execution, use the [SQLite replication and formal refinement brief](sqlite-replication.md). Start with DuckDB if the research question is whether specialization pays off. Run each role below in a separate context; do not hand the implementer the evaluator workspace. A source-visible rewrite is not a clean-room reimplementation.

## 1. Evaluator prompt (give this agent the project card)

> Before generating a candidate, pin an upstream commit, Capcov commit, dependency locks, runtime versions and platform. Write `contract.md` naming entry points, supported domain, observable outputs/effects, permitted differences, and exclusions. Assign workflow *families*, not individual parameter values, to public development, challenge, and sealed evaluation splits. Generate the sealed fixtures now, hash them, and keep them outside the implementer's workspace. Freeze oracle-query and repair-call budgets, generator seeds, minimization cost accounting, and the rule for stopping on zero discrepancies. Do not add scored cases after seeing the rewrite.
>
> Build two thin drivers with the same boundary. Read the [vector consumer skill](../../skills/capcov-vectors/SKILL.md), [`schema.py`](../../src/capcov/vectors/schema.py), [`recorder.py`](../../src/capcov/vectors/recorder.py), and [`replay.py`](../../src/capcov/vectors/replay.py). Define the `Operation`, cells, driver and resettable fixture. Record vectors from the actual pinned incumbent using the recorder; replay with the candidate driver and candidate artifact digest. For a stateful history reset before the history, not between steps. Explicitly inspect observable state through the public API. If the default normalization would mask significant user data, include a digest of a canonical encoding of the contract observation under a neutral key. Confirm an intentional test-only change to that observation fails replay; never score a planted mutant as the rewrite. Mark unavailable observations and nondeterministic reference outcomes as gaps, not passes. Deliver the adapter, pinned manifest, and a local record/replay command; do not invent a Capcov CLI flag.

## 2. Implementer prompt (give only the frozen public contract and public tests)

> Rewrite the entire contracted operation set in the target language. You may read the pinned upstream source and public tests. Do not shell out to the incumbent, call an equivalent library that already implements the task, inspect evaluator files, or special-case test cases. Return one runnable target, build instructions and dependency lock. Freeze its digest before any feedback.

## 3. Paired repair and scoring prompt (evaluator)

> Fork that exact candidate into three isolated workspaces. A sees ordinary test failures only. B gets ordinary failures plus raw discrepancies from a simple seeded generator. C gets ordinary failures plus discrepancies sought via Capcov vector replay, reduced to a reproducible input/history with the first observable divergence. Charge discovery and reduction to the same oracle-query ceiling for B and C; give all arms the same repair model, call ceiling and source access. Record actual cost, including unsuccessful searches. If an arm sees no discrepancy, allow no change. Do not leak evidence across arms or reveal sealed scores during repair.
>
> Score the initial and final binaries once against the same sealed families. Report numerators/denominators per family, newly fixed cases, regressions, gaps and cost; retain prompt transcripts, source/target hashes, raw traces, and minimized replay inputs. Separate intended migration decisions from compatibility failures. A green initial candidate means no demonstrated repair benefit. For a concrete worked comparison see the [snapshot rewrite](../../experiments/rewrite-snapshot/README.md).
